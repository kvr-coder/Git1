timeoff — Privacy Policy

Effective date: 20 June 2026

timeoff (also "Git1") is a parental screen-time tool: a phone app for the parent, a Windows agent on the child's PC, and a small sync server. This policy lists exactly what data we hold, why, and for how long — it mirrors the actual database schema 1:1. The same breakdown appears in the app under Settings → Privacy.

Who we are

Product: timeoff parental screen-time management.
Server: https://git1-server.onrender.com (open source).
Contact: kvaraciejus@gmail.com

The server is open source and can be self-hosted. Point the app at your own server and your data never touches our infrastructure.

What we NEVER collect

  • Message contents (DMs, Discord, iMessage, anything)
  • Screenshots or screen contents
  • Search history
  • Browsing URLs
  • Any third-party analytics SDKs
  • Any advertising IDs
  • We never sell or share any data with anyone, for any reason.

Children's data

timeoff is operated by a parent/guardian to manage their own child's device. Data about the child is collected at the parent's direction and is visible only to that parent (and any co-parent they explicitly invite). We do not build profiles, do not use this data for advertising, and do not disclose it to third parties.

Your controls

  • Clear my history on the server — Settings → Privacy.
  • Delete my account — Settings → Privacy.
  • Self-host the open-source server so your data never reaches us.

Where data lives

On the timeoff server (Render) at https://git1-server.onrender.com, in a SQLite database. The server code is public at github.com/kvr-coder/git1.

Changes to this policy

If we change what we collect, we update this page and the in-app Settings → Privacy screen together. The effective date above reflects the latest version.
